# Contributing

```sh
cargo fmt --all && cargo clippy --workspace --all-targets -- -D warnings
cargo test --workspace --exclude wikidata-node
cd crates/bindings/wikidata-node && corepack yarn install && corepack yarn build && corepack yarn test
```

- The tests use `fixtures/sample.json`, a small dump that covers every
  datatype, ranks, qualifiers, references, a property, lexemes and a
  class hierarchy, written the way Wikimedia's dumper writes. It is
  generated by `node scripts/make-sample-dump.mjs`; regenerate it rather
  than editing it by hand, and update the tests' expectations.
- Compressed variants (bzip2 with one and several streams, gzip, zstd,
  truncated and corrupt files) are made by the tests themselves.
- Changes to the bzip2 decoder must keep `cargo run --release -p
  wikidata-dump --example bz2_compare -- <dump.json.bz2>` agreeing with
  libbzip2 on a real dump (the first 50 MB are enough; see
  [bench/README.md](bench/README.md)).
- Behaviour that follows the dumps' or libbzip2's conventions should say
  so in a comment, with the reason when it is surprising (e.g. why claim
  filters ignore deprecated statements).
- Commits follow Conventional Commits (`feat:`, `fix:`, `perf:`, …).
